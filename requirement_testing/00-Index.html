Zinto Manual Testing Guide

Requirements Traceability — Client Acceptance Testing Pack
This pack contains 9 step-by-step guides that let you personally click through the Zinto platform — as a customer, a seller, an admin, and a delivery partner — and confirm that every requirement discussed for the project actually works in the live app. Every guide is written in plain, everyday language: no technical terms, just "tap this, you should see that."

How to use this pack

  • Each guide below is its own PDF. Open them one at a time, in the suggested order.
  • You will need test logins for the customer app, the seller portal, the admin panel, and (for Part 6) the delivery partner app. Ask your development team for these if you don't already have them.
  • Every test inside a guide is numbered and tagged with the original requirement reference (e.g. "Ref: Req #41") so it can be traced back to the requirements sheet.
  • Each test ends with an Expected Result — compare what you actually see on your screen to that line. If it matches, tick it off; if not, note it down for your development team.
  • Part 9 is different from the rest — it's a short reference document for background/technical items that aren't separate button-clicks, and simply points back to the other 8 guides.

Suggested testing order

  1. Start with Part 1 and Part 2 as a regular customer — this is the experience your own end users will have.
  2. Move to Part 3 (Seller Panel) using a seller test account, to see how a shop owner manages products and orders.
  3. Then test Part 4 and Part 5 (Admin Panel) using an admin test account, to see how the platform is configured and controlled.
  4. Test Part 6 (Delivery/Logistics) to see how an order gets a delivery partner and is delivered.
  5. Use Part 7 to walk through full order journeys end-to-end (placing, scheduling, cancelling) across all three apps.
  6. Use Part 8 to check the money side — refunds, wallet credits, and seller payouts.
  7. Finally, skim Part 9 for the background items that the earlier 8 guides already proved work.
